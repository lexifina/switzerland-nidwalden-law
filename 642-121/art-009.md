# Art. 9 Anschluss an das Hochspannungsnetz
1 Bei einem Anschluss an das Hochspannungsnetz liegt die Grenzstelle an einer Spannung von 50 kV oder mehr. Ein Anschluss an das Hochspannungsnetz wird nur erstellt, wenn die bezugsberechtigte Leistung aus technischen Gründen nicht aus dem Mittelspannungsnetz bezogen werden kann. Die Messung der Energie erfolgt zwingend auf der Netzebene 3. Ein Anschluss an das Hochspannungsnetz wird in einem Netzanschlussvertrag geregelt.
