# Art. 20 Dauer und Kündigung
1 Das Konkordat gilt auf unbeschränkte Dauer.
2 Jeder Konkordatskanton kann unter Einhaltung einer zweijährigen Kündigungsfrist auf Ende einer Leistungsperiode kündigen, erstmals auf das Ende der ersten Leistungsperiode.
3 Das Konkordat gilt zwischen den verbleibenden Konkordatskantonen weiter.
