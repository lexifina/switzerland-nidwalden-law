# Art. 29 4. Beginn der Arbeiten
1 Mit den Arbeiten darf erst begonnen werden, wenn der Kantonsbeitrag zugesichert ist.
2 Auf begründetes Begehren hin kann ein vorzeitiger Arbeitsbeginn bewilligt werden. Diese Bewilligung begründet keinen Anspruch auf eine Beitragsleistung.
3 Mit den Arbeiten ist innerhalb von zwölf Monaten nach erfolgter Beitragszusicherung zu beginnen. Nach Ablauf dieser Frist wird der Zusicherungsbeschluss hinfällig. In Ausnahmefällen kann eine Fristverlängerung bewilligt werden.
