# Art. 23 2. Aussteckungen, Modelle, Profile
1 Der Enteigner hat bis spätestens zum Beginn der Planauflage das Werk so darzustellen, dass für die Betroffenen ersichtlich wird, ob und wie sie beeinträchtigt werden.
2 Die zuständige Direktion entscheidet über die nötigen Vorkehren (Aussteckungen, Modelle, Profile usw.).
